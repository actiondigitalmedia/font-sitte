# font-site

Free/libre font catalog aggregation for building a font discovery website.

## Project

See [`free-font-site/README.md`](free-font-site/README.md) for the full aggregation pipeline, schema, and usage.

**Current catalog:** 2,013 commercial-safe font families from Google Fonts, Fontshare, Font Squirrel, Velvetyne, League, and Nerd Fonts.

```bash
cd free-font-site && pip install -r requirements.txt && python3 scripts/aggregate.py
```
