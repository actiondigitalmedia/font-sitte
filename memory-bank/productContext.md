# Product Context

## Why this exists
Designers search Google for free fonts and land on DaFont/FontSpace — often with murky licenses. **font-sitte** aggregates **commercial-safe** libre fonts with clear licenses and live previews.

## Problems solved
- License ambiguity on free-font SERPs
- Fragmented sources (Google Fonts, Fontshare, etc.)
- Expensive SEO suites for a catalog that needs **data + templates**, not dashboards

## How it should work
1. User lands on entity or hub page from search
2. Sees specimen + commercial-use clarity immediately
3. Downloads/uses via official source link
4. Discovers similar fonts via internal links
5. Operators improve rankings via GSC + cheap SERP data + Cursor agents

## UX / SEO goals
- Trust first (license above the fold)
- Fast static pages
- Every font has a crawlable URL
- "Free fonts you can actually use commercially" positioning
