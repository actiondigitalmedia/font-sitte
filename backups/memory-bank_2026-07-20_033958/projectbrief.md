# Project Brief: font-sitte + SEO stack

## Project name
**font-sitte** — Free/libre font catalog + SEO operations plans

## Repository
- GitHub: `github.com/actiondigitalmedia/font-sitte`
- Catalog work: branch `cursor/free-font-aggregation-43e3` (PR #1)
- SEO plans: branch `cursor/seo-strategy-plans-d92e`

## Core goals
1. Aggregate commercial-safe libre fonts into a browsable catalog site
2. Rank for free/commercial-use font discovery queries via **programmatic SEO**
3. Run SEO with **max impact / min cost** (Cursor + OpenSEO + DataForSEO + GSC) — not Semrush/Ahrefs subscriptions
